# Abrham Melesse Birru — Portfolio

Static portfolio (HTML + Tailwind CSS, compiled at build time).

- Source: `src/index.html`, styles: `src/input.css`, static files: `public/`
- `npm install && npm run build` → outputs `dist/`
- `npm run preview` → serves `dist/` on http://localhost:4173

Deploys on Vercel using `vercel.json` (build command `npm run build`, output `dist`).
